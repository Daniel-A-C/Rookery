# Dynamic Wallpaper Media Folder

Drop your looping GIFs or video files here to play them unobtrusively as your desktop wallpaper.

Supported formats:
- Images / Animated GIFs: `.gif`, `.webp`, `.png`, `.jpg`, `.jpeg`
- Videos (muted, looping): `.mp4`, `.mov`, `.webm`, `.m4v`

All files added to this folder (other than the bundled open-source `ambient-twilight-loop.gif`) are automatically ignored by Git.
